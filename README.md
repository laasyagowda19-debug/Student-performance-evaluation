
# Student Performance Prediction System

## Project Description
A Python mini project that analyzes student marks,
attendance, and daily study hours.

## Features
- Accepts student details
- Predicts likely pass or improvement needed
- Sorts students by marks
- Identifies students needing improvement
- Saves input and results to CSV files

## Technologies
- Python
- CSV file handling
- Dictionaries and tuples
- Functions and lambda
- Object-oriented programming

## How to Run
Open a terminal in the project folder and execute:

python src/main.py

## Note
This version uses rule-based prediction.
It does not train a machine-learning model.
